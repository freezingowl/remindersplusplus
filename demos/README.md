# Cue Lock Screen demos

These two unedited, participant-provided iPhone screen recordings demonstrate Cue's core experience: a personal AI available through Back Tap and visible on the Lock Screen, without opening the Cue app.

| File | Flow | Capture details |
| --- | --- | --- |
| [`back-tap-add-calendar.mov`](back-tap-add-calendar.mov) | Back Tap → system text input → “Meeting at hackathon at 11 am today” → **Added to Calendar** | Original QuickTime recording; 28.7 seconds; 1170 × 2532; HEVC/AAC. |
| [`back-tap-calendar-availability.mp4`](back-tap-calendar-availability.mp4) | Back Tap → system text input → ask about free time tomorrow → **Free after 10 AM tomorrow.** | Original MP4 recording; 23.4 seconds; 1170 × 2532; HEVC/AAC. |

The iPhone's system input/authentication behavior and Live Activity lifetime are controlled by iOS. The videos demonstrate the recorded Lock Screen flows; they do not replace the setup, device-permission, or Apple-push limitations documented in the repository root [README](../README.md).
